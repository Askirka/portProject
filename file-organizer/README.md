# ПОРТ — Программа Организации Разнообразных Типов

Утилита на Go для автоматической организации файлов по категориям. Программа сканирует выбранную директорию, сортирует файлы по их расширениям, перемещает их в соответствующие папки, ведёт лог операций и формирует подробный отчёт о проделанной работе.

---

## Возможности

- 📂 Автоматическая сортировка файлов по расширениям
- 📄 Поддержка категорий:
    - Documents
    - Images
    - Music
    - Video
    - Archives
- 📝 Логирование всех операций в `organizer.log`
- 📊 Генерация отчёта со статистикой
- 📦 Подсчёт количества файлов и их общего размера
- ⚠️ Автоматическая обработка конфликтов имён файлов
- 📁 Возможность выбрать любую директорию для сортировки

---

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/Askirka/portProject.git
```

Перейдите в папку проекта:

```bash
cd portProject
```

Соберите программу:

```bash
go build
```

или

```bash
go build -o file-organizer
```

---

## Запуск

Запустите программу:

```bash
go run .
```

или

```bash
./file-organizer
```

После запуска программа попросит указать путь к директории.

Если просто нажать **Enter**, будет использована текущая рабочая директория.

---
